# Repositorio_de_Github_Express
Repositorio para actividades relacionadas a reacts, utilizando herramientas como GitHub, Node y Express.

Proyecto Final: Sistema de Gestión Escolar y Vehicular

Este proyecto corresponde al backend de un sistema integral desarrollado como trabajo final para la asignatura de Desarrollo Web del Lado del Servidor en la Universidad Autónoma de Sinaloa.

El sistema permite la gestión de registros de alumnos, materias, inscripciones (relación alumno–materia) y vehículos. Está construido bajo una arquitectura híbrida que integra tanto bases de datos relacionales como no relacionales.

Tecnologías Utilizadas:
Node.js y Express (Servidor backend)
PostgreSQL (Base de datos relacional utilizando el paquete pg)
MongoDB y Mongoose (Base de datos NoSQL para la colección de vehículos)
Postman (Herramienta para pruebas y validación de la API)
